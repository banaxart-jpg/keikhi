# 菌学（/fungi/）

キノコ・菌類の 4 択クイズアプリ。Phase 1 (最小実装)。

## 使い方
- ランチャーから [菌学] をタップ
- 4 つの選択肢から答えを選ぶ → 正解なら緑、間違いなら赤
- 解説が出るので読んでから「次へ」
- 1 セッション = 10 問。間違えた問題はそのセッション中にもう一度出る (RETRY バッジ付き)
- 終わったら「もう一回」で別のシャッフルでまた 10 問

## 問題を追加する

`apps/fungi/index.html` の冒頭 `QUESTIONS` 配列に追記するだけ:

```js
{
  q: "問題文",
  choices: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: 0,                    // 正解の index (0〜3)
  cat: "毒性",                  // タグ表示用。「毒性 / 食用 / 成分 / 薬理 / 生態 / 形態」など好きに
  img: "https://...jpg",        // (任意) 画像 URL。Wikimedia Commons 推奨
  explain: "<b>強調</b> 付き解説OK", // (任意) 解答後に出る解説。HTML 可
}
```

### 画像付きの問題

`img` に URL を 1 行足すだけ。Wikimedia Commons は `Special:FilePath` を使うとリンクが安定:

```
https://commons.wikimedia.org/wiki/Special:FilePath/<ファイル名>.jpg?width=600
```

将来的には Cloud Storage に自分で撮ったキノコ写真をアップする仕組みも追加できる。
