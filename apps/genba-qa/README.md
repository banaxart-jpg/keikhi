# 現場質問（/genba-qa/）

現場ごとの確認事項をチャット形式で回すアプリ。お客さん・設計事務所など
**社外の人も Google ログインすれば参加できる**（URL を送るだけ。アプリ一覧には出ない）。

## 使い方
- ランチャーから [現場質問] をタップ（社外の人には URL を直接送る）
- 現場タブで絞り込み、大タブは **質問中 / 回答完了** の2つ
- 「＋」で質問をあげる（質問文がそのままタイトル。画像も付けられる）
- 質問を開くとチャット。**誰でも返信・画像添付できる**
- 誰かが「✓ 完了にする」を押すとチャットに記録が残って **回答完了タブへ移動**
- 状況が変わったら「未回答に戻す」→ これも記録が残って質問中タブへ戻る
- 質問中の項目には「検討中 ⇄ 確認中」のチップを付け替えられる
- 初回だけ名前を入力（端末に記憶。チャットの表示名になる）

## 仕組み
- データは keihi-api (Cloud SQL): `genba_qa_threads` + `genba_qa_messages`
- 完了/差し戻しは `kind='system'` のメッセージとして履歴に残る
- **認証**: `/api/genba-qa*` は「Firebase ログイン済みなら誰でも」（kotonoha と同じ例外扱い）。
  つまり URL を知っていて Google アカウントがあれば社外でも読める。削除だけは社内限定
- 現場一覧は共通の `GET /api/sites`（読み取りは外部開放済み）
- 画像は縮小して base64 で DB 保存（sekkei-qa と同じ方式。高解像度が要るなら将来 Storage 化）
- スレッドを開いている間は 5 秒ポーリングで新着を反映
