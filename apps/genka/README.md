# 原価計算（/genka/）

現場ごとに「見積金額 − 各業者の金額 ＝ 利益」をざっくり出すシンプルなアプリ。金額は**万単位**で入力。

## 使い方
- ランチャーから [原価計算] をタップ
- 右上「＋現場」→ **現場名**（既存の現場名は候補から選べる）と**見積金額（万）**を入力
- **業者**を行で追加：業者名＋金額（万）。「業者を追加」で何行でも
- 下のサマリーに **原価合計 / 利益 / 利益率** がリアルタイムで出る（円換算も小さく表示）
- 「登録／保存」。一覧では現場ごとに利益（＋緑／−赤）と利益率が並ぶ
- 一覧上部に **見積合計 / 原価合計 / 利益合計** の全体サマリー

## みんなで共有
- 経費・タスクと同じ **keihi-api (Cloud SQL)** に保存。ログインしていれば端末・人をまたいで共有
- 現場名の候補は `/api/sites`（現場アプリの登録）から取得。自由入力もOK

## データ / API
- テーブル `genka_projects`（`vendors` は `[{name, amount}]` の JSONB、`amount`/`quote` は**万**単位の数値）
- `GET/POST/PUT/DELETE /api/genka`
- 利益・原価・利益率はクライアント側で計算（`利益 = 見積 − Σ業者`、`利益率 = 利益 / 見積`）

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- サーバー側は `apps/keihi/server/index.js` の `/api/genka*`
