# 会議の文字起こし（/gijiroku/）

録音しながら 15 秒ごとに文字にしていく会議用アプリ。PC なら画面共有も一緒に残せて、あとで Claude のチャットからそのまま読める（MCP）。

## 使い方
- ランチャーから [会議の文字起こし] をタップ
- 会議名を入れて「始める」→ そのまま録音スタート。15 秒ごとに文字が出てくる
- PC では「画面も」で画面共有。画面が変わったときだけ静止画を残す
  - オンライン会議（Meet / Zoom のブラウザ版など）は**タブを共有して「音声も共有」をオン**にすると相手の声も文字になる
- 「一時停止」「終了」。あとから開いて「続きを録音」もできる
- Claude で読む: 「Claude につなぐ」の URL を claude.ai のカスタムコネクタに 1 回登録 →
  会議画面の「Claude 用」でコピーした文をチャットに貼る（「〇〇の会議まとめて」だけでも探してくれる）

## 仕組み
- 録音: MediaRecorder を 15 秒ごとに切り替え、チャンクを `POST /api/meeting/:id/audio` → Gemini 2.5 flash で文字起こし → 画面に追記
- 画面: getDisplayMedia の映像を 2 秒ごとに縮小比較し、変化して落ち着いたら JPEG（最大 1600px）を `POST /api/meeting/:id/frame` → GCS
- 「いま」の行はブラウザ内蔵の音声認識による簡易字幕（保存しない。iPhone では出ない）
- 音声そのものは保存しない。残るのは文字と静止画だけ
- サーバー / MCP: `apps/keihi/server/meeting-lib/`

## 注意
- iPhone は画面を点けたまま（スリープ・アプリ切替で録音が止まる）。画面共有は PC のみ
- 送れなかったチャンクは上の「再送」で送り直せる（ページを閉じると消える）
