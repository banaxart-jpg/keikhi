# 銀行（/ginko/）

銀行の取引CSVを取り込んで「取引」タブに送信する。

## 使い方
- ランチャーから [🏛 銀行] をタップ
- PayPay銀行の管理画面から取引CSVをダウンロード
- 「CSVを選択」→ 自動で内容パース＋分類
- プレビューで内容確認、不要な行は除外チェック
- 「送信」で取引タブに一括追加

## 対応銀行
- ✅ PayPay銀行
- 🔜 みずほ・三井住友など（後日）

## 自動分類のルール（摘要文の正規表現マッチ）
- `給与/ｷｭｳﾖ` → 固定費・給料
- `airbnb/booking` → 旅館・各チャネル
- `tepco/電気` → 固定費・光熱費
- `google/adobe/indeed/openai/chatGPT` → 固定費・web
- マッチしない → 「未分類」(取引タブに入った後、手で直す)

## サーバー
- `POST /api/ginko/parse` — CSV(base64)を受け取り、行配列を返す
- 送信は既存の `POST /api/tx/append` を1行ごとに呼ぶ

## ファイル構成
- `index.html` — UI（Vue 3, CDN）
- `icon.svg` — アイコン
