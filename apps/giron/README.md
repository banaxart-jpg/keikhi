# AI議論（/giron/）

3人のAI（Gemini）にお題を投げて、キャラ違いで議論させるミニアプリ。

## 使い方
- ランチャーから 🗣️ AI議論 をタップ
- お題を入力（例：「会社の昼休みは1時間と2時間どっちがいい？」）
- 3人の名前・性格はそのままでも、編集してもOK
- 「議論スタート」で1ラウンド（3人が1発言ずつ）
- もう1回押すと続きの議論が進む
- 「まとめる」で論点と結論を出す
- 「リセット」で履歴クリア

## 仕組み
- フロント：1ラウンドごとに `POST /api/debate` を3回（speakerを順に変えて）
- サーバー：`keihi-api` が Gemini にプロンプトを投げて1発言生成
- まとめモードは `summary: true` を渡すと議論ログ全体から結論を生成

## ファイル構成
- `index.html` — UI + ロジック
- API: `apps/keihi/server/index.js` の `/api/debate`
