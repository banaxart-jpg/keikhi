# 領収書（/keihi2/）

経費 と同じ DB を使う「**撮影連発 → 後でまとめて SORT**」型の領収書アプリ。
レシートが溜まってる時に1枚1枚 AI 読取を待たずに撮影だけ高速で済ませて、
あとで TikTok 風スワイプで現場を割り当てる。

## 使い方
- ランチャーから [領収書] をタップ → 名前を選ぶ
- **「📷 撮影」** を連打。撮ったらすぐ次が撮れる（読取は裏でシリアル処理）
- 画面下のサムネに「読取中…」「✓ ¥XXX」「⚠️ 失敗」が出る
- 上部の **「SORT N →」** で SORT 画面へ
- スワイプ式フルスクリーンで 1 枚ずつ表示。**現場ボタンをタップ → スルッと次へ**
- 「現場決めずに一旦スキップ」したい時は **上に手動スワイプ**

## 経費 との関係
- 同じ Cloud SQL の `records` テーブルを共有
- スプレッドシート連携の URL も共有（localStorage の `sheetUrl`）
- 領収書 で登録したレコードは経費 の一覧にも出る（同一データ）
- `site` が空文字 `""` のレコードを「SORT 待ち」と扱う

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- DB / API / 画像保存 は経費1の Cloud Run (`keihi-api`) を流用
