# 経費2（/keihi2/）

経費1 と同じ DB を使う「**撮影連発 → 後でまとめて仕分け**」型の経費アプリ。
レシートが溜まってる時に1枚1枚 AI 読取を待たずに、撮影だけ高速で済ませて、
あとで現場ボタンをタップしていくフロー。

## 使い方
- ランチャーから [経費2] をタップ → 名前を選ぶ
- **「📷 撮影」** を連打。撮ったらすぐ次が撮れる（読取は裏でシリアル処理）
- 画面下のサムネに「読取中…」「✓ ¥XXX」「⚠️ 失敗」が出る
- 上部の **「仕分け N →」** で未仕分け一覧へ
- 各カードの **現場ボタン** をタップ → その現場で仕分け確定（同時にスプレッドシートにも送信）

## 経費1 との関係
- 同じ Cloud SQL の `records` テーブルを共有
- スプレッドシート連携の URL も共有（localStorage の `sheetUrl`）
- 経費2 で登録したレコードは経費1 の一覧にも出る（同一データ）
- `site` が空文字 `""` のレコードを「未仕分け」と扱う

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- DB / API / 画像保存 は経費1の Cloud Run (`keihi-api`) を流用
