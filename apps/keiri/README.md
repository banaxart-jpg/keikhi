# 経理（/keiri/）

「取引」タブを集計して、月別の売上・支出・利益・現場別・カテゴリ別を一目で見るダッシュボード。

## 使い方
- ランチャーから [📊 経理] をタップ
- 上の月ナビで対象月を切替
- KPI 3つ（売上 / 支出 / 利益）と前月比
- 現場別ランキング: 売上/原価/粗利
- カテゴリ別支出ランキング
- 月次推移ミニグラフ（過去12ヶ月）
- 行タップで該当する取引一覧にドリルダウン

## データソース
- Google Sheets `TX_SHEET_ID` の「取引」タブを読むだけ（書き込みなし）
- サーバー側で 5 分キャッシュ（連打しても Sheets API を叩きすぎない）

## サーバー
- `GET /api/keiri/summary?month=YYYY-MM` — 月次の集計 + 前月比 + 12ヶ月推移
- `GET /api/keiri/transactions?month=YYYY-MM&site=&category=&subcategory=` — ドリルダウン用の生取引

## ファイル構成
- `index.html` — UI（Vue 3, CDN）
- `icon.svg` — アイコン
