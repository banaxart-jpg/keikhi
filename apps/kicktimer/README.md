# ラウンドタイマー（/kicktimer/）

キックボクシングのトレーニング用タイマー。3分ラウンド + 1分休憩をラウンド数ぶん繰り返して、ゴング音で知らせる。

## 使い方
- ランチャーから [🥊 ラウンドタイマー] をタップ（スマホ横向き推奨）
- ラウンド数を − / ＋ で選んで「開始」
- 10秒カウント → ゴングでラウンド開始。画面全体が色で切り替わる（赤=ラウンド / 緑=休憩）
- 今何ラウンド目か（R 3/5）と残り時間がデカ文字で出る
- 残り10秒で拍子木、ラウンド終了でカンカンカン、全ラウンド終了でゴング3発
- 画面タップ（またはボタン）で一時停止 / 再開
- 動作中は Wake Lock で画面がオフにならない（対応ブラウザ: iOS Safari 16.4+ / Android Chrome）

## 仕組みメモ
- サーバー・認証なしの1ファイル Vue アプリ。音は WebAudio で合成（音源ファイルなし）
- タイマーは `Date.now()` 基準で計算（setInterval のドリフトの影響を受けない）
- URL パラメータで時間を変えられる: `/kicktimer/?round=120&rest=30&ready=5`（秒）
