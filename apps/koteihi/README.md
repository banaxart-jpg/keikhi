# 固定費（/koteihi/）

毎月発生する固定費（給料・家賃・保険・税金・サブスク等）を1タップで「取引」シートに登録。

## 使い方
- ランチャーから [📅 固定費] をタップ
- 1回だけマスタを登録（給料 小西 ¥370,000、家賃 中目黒 ¥4,400, etc）
- 月初に開く → 今月分を確認（金額違うのだけ編集）→ 「送信」ボタンで全部「取引」タブに一気に追加
- 送信済みの月は ✓ で見えるので、二重送信しない

## マスタ項目の中身
- **小分類**: 給料 / 家賃 / 保険 / 税金 / 車両費 / 通信費 / web 等
- **対象**: 小西 / 名取 / 中目黒事務所 / 社会保険 / chatGPT 等
- **金額**: デフォルト金額（送信時に上書き可）
- **支払日**: 月の何日に発生するか（取引タブの「日付」に使う）

## ファイル構成
- `index.html` — UI + ロジック（Vue 3、Firestore）
- `icon.svg` — アイコン

## データ
- Firestore `koteihi_items` ← マスタ項目（共有）
- Firestore `koteihi_sent/{YYYY-MM}` ← 送信履歴（共有）
