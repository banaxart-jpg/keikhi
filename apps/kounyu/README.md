# 購入品・到着（/kounyu/）

ネット購入品を「買う → 注文（発送）→ 到着」で追い、**到着予定カレンダー**で「いつ・どの現場の・どこに届くか」を見るアプリ。手入力は最小限。

## 使い方
- ランチャーから [購入品] をタップ
- まず **「買うもの」** を追加していく（品名だけでOK）
- 注文したら item の **「注文した」** → 発送日 or 到着予定を入れる
- 届いたら **「到着✓」**

## 手入力を減らす工夫
- **現場はタップで選ぶだけ**（`/api/sites` の現場リストを流用。手入力も可）
- **到着場所はボタン**（会社/現場/倉庫/自宅＋よく使うものを記憶）
- **数量はステッパー**（−/＋）
- **発送日を入れたら到着予定を自動**（既定：翌々日 +2日。「翌日着/翌々日着/今日着」ボタンあり）

## タブ
- **リスト**：買うもの / 注文済み（到着待ち）/ 到着済み の3グループ
- **到着カレンダー**：月表示で到着予定を表示。日をタップでその日の到着一覧

## データ / API
- テーブル `kounyu_items`（name / site / destination / qty / unit / status(tobuy|ordered|arrived) / ship_date / arrival_date / url / memo）
- `GET/POST/PUT/DELETE /api/kounyu`。現場候補は `GET /api/sites` を流用

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- サーバー側は `apps/keihi/server/index.js` の `/api/kounyu*`
