# 見積（/mitsumori/）

工事の見積書を、**項目をタップで選ぶだけ**で作るアプリ。合計・消費税は自動計算。飲食店内装/厨房工事の項目をプリセット収録。

## 使い方
- ランチャーから [見積] をタップ → 「新規」
- 顧客名・現場・発行日を入れる
- 「項目を追加」→ **プリセット項目をタップ**で行が増える（検索も可 / 無い項目はその場で追加）
- 各行の **数量・単価** を入れると **金額が自動**。**小計・消費税・合計も自動**
- 「保存」。一覧に合計つきで並ぶ。タップで再編集

## 「簡単」の工夫
- **プリセット項目**（墨出し / 厨房防水 / ダクト作成 … 42項目）をタップで選ぶだけ
- **前回の単価を記憶**：過去の見積で使った単価を項目ごとに覚えて、次から自動で入る（「前回 ¥XX」表示）。チームの見積全体から拾うので**みんなの相場が溜まる**
- **消費税率は編集可**（既定10%）

## みんなで共有
- 経費・タスクと同じ **keihi-api (Cloud SQL)** に保存。ログインすれば端末・人をまたいで共有

## データ / API
- テーブル `mitsumori_estimates`（customer / site / issued_on / tax_rate / items=JSONB[{name,qty,unit,price}] / memo）
- `GET/POST/PUT/DELETE /api/mitsumori`

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- サーバー側は `apps/keihi/server/index.js` の `/api/mitsumori*`

## 主な機能
- [x] **プレビュー → PDF/印刷**：見積書のキレイなレイアウトで表示し、`window.print()` で PDF 保存・印刷（iOS の共有シートから客に送れる）。自社情報（会社名/電話/登録番号）は端末に保存して見積書に載る
- [x] **複製**：既存の見積を複製して新規作成
- [x] **材料/手間/外注/経費の区分**：各項目に区分をつけ、サマリーで区分別に集計
- [x] **原価計算(genka)へ連携**：見積の合計金額を原価計算アプリの「見積金額」に送る（そこで実際の業者原価を入れて利益を見る）
- [x] **AI 下書き**：工事内容を一言書くと（`POST /api/mitsumori/draft`, Gemini）項目を下書き
