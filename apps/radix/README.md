# Radix（/radix/）

「言葉の進化を旅する」語源アプリ。企画は本気の長期プロジェクトで、これはその**第一歩＝単語比較の画面**。

## 今できること（MVP step ②）
- 意味（母・父・名前・夜・星・三・新しい・水）をタップで選ぶ
- ドイツ語 / 英語 / フランス語 / イタリア語 / スペイン語 / ギリシャ語 の **6言語が並ぶ**
- **共通の子音（語根の骨組み）が金色でハイライト**
- 各言語が **ゲルマン系 / ロマンス系 / ギリシャ系** に色分け
- 「水」だけは *wódr̥ 系とラテン aqua 系に分かれる例＝「なぜ違う？」解説つき
- ログイン・サーバー不要（データは `index.html` 内の `CONCEPTS` 配列）

## 単語を増やすには
`index.html` の `CONCEPTS` 配列に1エントリ足すだけ。`keys` に光らせたい子音（ラテン+ギリシャ）を書く。
