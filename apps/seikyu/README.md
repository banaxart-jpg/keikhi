# 請求書（/seikyu/）

「これから払う紙（光熱費・税金・通信費 等）」を撮影して未払い管理するアプリ。
払った後の領収書・コンビニ払込控えは **経費アプリ (`/keihi/`)** に登録する。

## 使い方
- ランチャーから [📄 請求書] をタップ
- 「📷 撮影」で請求書を撮ると AI が金額・発行元・支払期限を読み取る
- 確認 → 「登録する」で保存
- 一覧で「未払い / 支払済」を切替
- 各行の右の ⚪︎ をタップで「支払済」に切替（もう一度押すと未払いに戻る）
- 支払期限が3日以内なら ⏰、過ぎてれば 🚨 が出る

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- スキャンは経費と同じ `/api/scan` を使用（`kind:"invoice"` パラメータで切替）
- データはブラウザの localStorage に保存（同じスマホでログインしてれば残る）

## スプレッドシート連携
一覧画面の「スプレッドシート連携」から Apps Script の URL を登録すると、
登録するたびに月別タブ（例：`2026-05-請求書`）に1行 append される。
スクリプトの中身は経費アプリの `sheet-apps-script.gs` を流用してOK
（タブ名のサフィックスは GAS 側で工夫する）。

## 残課題
- [ ] 支払期限が近づいたらブラウザ通知（PWA + FCM）
- [ ] 支払済 → 経費アプリ側に「コンビニ払込控え」として送り込む導線
- [ ] 同じ請求書（東京電力 4月分 など）を重複登録しないようガード
