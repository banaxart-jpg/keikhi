# 鮫学（/shark/）

サメ (鮫) の 4 択クイズアプリ。`fungi` と同じ構造のスピンオフ。

## 使い方
- ランチャーから [鮫学] をタップ
- ホームで「通常 / 図鑑 / 復習 / 成績」から選ぶ
- 通常モード = 全 30 問から 10 問
- **図鑑** = 全種をカードで一覧。**2 連続正解**でそのサメが「制覇」点灯（誤答すると連続記録が 0 に戻って制覇が外れる＝もう一度狩りに行く動機）
  - まだ正解してないサメは「?」シルエット、挑戦中はグレー＋「あと1」、制覇はフルカラー＋✓
  - カードをタップで詳細シート（写真・解説・制覇状況）。下にドラッグで閉じる
  - クイズ結果画面で新たに制覇するとバナーで通知
- 復習モード = 過去に 1 回でも誤答した問題プールから 10 問
- 成績 = 累計セッション / 累計正答率 / 苦手 top10
- 進捗は Firestore (`shark_progress/{uid}`) に保存、端末またぎ同期
  - `perQuestion[id]` に `tries / correct / streak` を保存（`streak` = 現在の連続正解数、図鑑の制覇判定に使用）

## 問題を追加する

`apps/shark/index.html` の冒頭 `QUESTIONS` 配列に追記:

```js
{
  q: "問題文",
  choices: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: 0,                    // 正解の index (シャッフル前の元配列での位置)
  cat: "種同定",                // 表示用タグ
  wikiTitle: "Great_white_shark", // (任意) 英語 Wikipedia 記事名 → サムネ自動取得
  img: "https://...jpg",        // (任意) 手動で画像 URL 指定。wikiTitle と併用したら img 優先
  explain: "<b>強調</b> 付き解説OK",
}
```

## ファイル構成
- `index.html` — UI + クイズロジック + 問題プール (1 ファイル完結)

## 残課題
- [ ] 問題プールを増やす (40〜60 問目標)
- [ ] カテゴリ (種同定 / 解剖 / 繁殖 / 生態 / 進化 / 人間) でタブ絞り込み
- [ ] 自前の写真も載せられる仕組み (Cloud Storage)
- [x] 図鑑コンプリート (2 連続正解で制覇 / コレクション一覧)
- [ ] 図鑑を fungi (菌学) 側にも展開
- [ ] 連続日数 (streak) / タイムアタックなど他のやり込み要素
