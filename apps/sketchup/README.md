# My SketchUp（/sketchup/）

SketchUp のモデルを読み込んで、スマホでぐるぐる回して見るビューア。
社内がモデルをアップロードして共有リンクを作り、お客さんに URL を渡して見てもらえる。

## 使い方

### 自分で見る
- ランチャーから [view_in_ar My SketchUp] をタップ（Google ログイン必須）
- 「ファイルを選ぶ」で SketchUp からエクスポートしたファイルを開く
- 1本指で回転、2本指でズーム・移動
- **断面**: 右下のハサミボタン → 透明な板をモデルに差し込むイメージで切れる
  - スライダー = 板の位置、「上から / 横から / 前から」= 板の初期向き
  - バー右端の傾きボタン = **スマホの傾きに板の向きが連動**（板を手で持って傾ける感覚）
  - 切り口はベタ塗りの面で表示（ステンシル方式、中が詰まって見える）
- 右下の傾きボタンで **ジャイロ見回し**（iPhone を傾けて上から・下から見る）
- 右下のボタンで視点リセット / 別のファイルを開く

### あげたモデルの管理（社内のみ）
- トップの「あげたモデル」から過去にアップした一覧を開ける
- タップで 開く / リンクをコピー / 削除（2度押しで確定）

### お客さんに共有する（社内のみ）
- モデルを開いた状態で右下の共有ボタンをタップ
- アップロードが終わると `/sketchup/?m=xxxx` の共有リンクが出る
- コピー or 共有ボタンで LINE などに送る
- 受け取った人は **Google (Gmail) でログインするだけ**で閲覧できる
  （リンクを知ってる人だけが開ける。ランチャーや他のアプリには入れない）

## 対応ファイル
- ZIP / DAE (Collada) / OBJ (+MTL) / STL / GLB / GLTF
- SketchUp の OBJ 書き出しは「obj + mtl + テクスチャフォルダ」一式で出てくるので、
  **書き出し時にできる .zip をそのまま選ぶ**のが一番ラク（ブラウザ内で展開する）
- PC ならフォルダごとドラッグ&ドロップでも OK
- `.skp` そのものはブラウザで読めないので、SketchUp 側で「エクスポート」してから開く
  - 色・素材も見たいなら DAE がおすすめ
- テクスチャ画像が別ファイルの時は、モデルと画像をまとめて選択すれば表示される
- サイズ上限: 1ファイル 14MB、1モデル合計 60MB

## ファイル構成
- `index.html` — UI + ロジック（three.js を CDN から読み込み）
- API は `keihi-api` (`apps/keihi/server/index.js`) の `/api/sketchup/*` に相乗り
  - モデル実ファイルは GCS（`sketchup/<id>/<filename>`）、メタ情報は `sketchup_models` テーブル
  - 共有モデルの GET だけ社外の Google 認証ユーザーにも開放（アップロードは社内限定）
