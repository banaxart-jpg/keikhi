# My SketchUp 距離センサー（ESP32 + VL53L1X）

スマホの背中に貼るレーザー距離計。壁までの実測距離でビューアの
「近づく/断面が進む」を動かすための送信機。

## 買うもの
- VL53L1X モジュール（I2C 接続のもの、500〜1,000円くらい）
- あとは手持ちの ESP32 とモバイルバッテリー、両面テープ

## 配線
| VL53L1X | ESP32 |
|---|---|
| VIN | 3V3 |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |

## 手順
1. Arduino IDE に `rangefinder.ino` を開く
2. ★の3ヶ所（Wi-Fi 名 / パスワード / CHANNEL）を書き換える
   - CHANNEL は 12 文字以上の適当な英数字。例: `a3f9c2e81b44`
3. ESP32 に書き込み。シリアルモニタに `1234 mm` が流れれば送信できてる
4. スマホで `https://keihi-496002.web.app/sketchup/?dev=<CHANNEL と同じ値>` を開く
   （1回開けば覚えるので、以降は普通の URL で OK）
5. モデルを開いてジャイロボタン ON →「距離センサーと接続しました」と出たら成功。
   壁に向かって踏み込むと近づいて断面が進む

## 仕組み
```
VL53L1X → ESP32 → Wi-Fi → keihi-api (/api/sketchup-range/<channel>) → アプリがポーリング
```
- HTTPS ページから宅内機器へ直結できないブラウザの制約を、サーバ中継で回避してる
- 人が横切った時の値ワープはアプリ側のフィルタで吸収
  （50cm 超の瞬間ジャンプは保留、5 回連続で留まったら本当の移動と判定 + 中央値）
