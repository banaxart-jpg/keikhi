# 世界制覇めし（/tabemap/）

東京周辺で世界の料理を食べて記録し、国ごとに「制覇」を塗りつぶして制覇率（%）を見るアプリ。友達と共有。

## 使い方
- ランチャーから [世界制覇めし] をタップ
- 上部の **世界ピン地図**：各国を実際の位置にプロット。制覇した国はその場所で色が点く（＝制覇したとこに色つけ）。ピンをタップで詳細
- 下は大陸別の**国旗ボード**。食べた国は色が点いて✓、未制覇はグレー
- **制覇率（何%）／ N / 58 か国**を表示
- 国をタップ → その国の**店名・エリア・写真・メモ・誰と食べたか**。「この国を記録する」で追加
- 記録は **店名 / エリア / 日付 / 誰と食べた（複数OK）/ メモ / 写真（最大3枚）**

## 友達と一緒に食べた記録
- 「誰と食べた？」は**カンマ区切りで複数人**（例：`自分, どんちゃん`）
- 上の **チップ**で人を選ぶと、その人と一緒に食べた国だけが地図・ボードに点く
  （例：`どんちゃん` を選ぶと「どんちゃんと制覇した国」と制覇率が出る）
- 経費・タスクと同じ **keihi-api (Cloud SQL)** に保存。ログインすれば端末・人をまたいで共有
- 友達は Google ログインすれば参加＆記録を追加できる（社外の人もログイン可）

## データ / API
- テーブル `tabemap_visits`（country=国名キー / restaurant / area / eater / memo / photos=base64配列(最大3) / visited_on）
- `GET/POST/PUT/DELETE /api/tabemap`、`GET /api/tabemap/:id/photos`（写真は別取得）
- 対象は「東京で食べられる世界の料理」58 か国を大陸別に収録（`REGIONS` 配列）。増やすのは配列に足すだけ

## ファイル構成
- `index.html` — UI + ロジック（1ファイル完結）
- サーバー側は `apps/keihi/server/index.js` の `/api/tabemap*`
