# タスク（/task/）

小西と名取の間でやることをやり取りするボード。「相手にお願いする」「自分宛のやること」を共有。

## 使い方
- ランチャーから [✅ タスク] をタップ
- 画面は3列：**← 相手 / 一緒に / 自分 →**
- 右下の `+` でタスク追加。「誰がやる」「優先度」「期限（任意）」
- カードを **横にずらす** と隣の列へ移動（担当替え）
  - 左にずらす → 相手にお願い
  - 右にずらす → 自分でやる
  - 真ん中 → 一緒にやる
- カードをタップで展開 → 完了 / 優先度サイクル / 編集 / 削除
- 完了したら薄くなって下に回る。完全削除は手動

## 通知
- 相手が新規追加したタスクで自分にも関わるもの → 赤丸
- アプリを開いた時点で既読扱い

## ファイル構成
- `index.html` — UI + ロジック
- `icon.svg` — アイコン (cloudbuild で PNG に変換)
