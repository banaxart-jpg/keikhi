# タスク（/task/）

小西と名取の間でやることをやり取りするボード。「相手にお願いする」「自分宛のやること」を共有。

## 使い方
- ランチャーから [✅ タスク] をタップ
- 右下の `+` でタスク追加。「相手 / 自分」「優先度 高/中/低」「期限（任意）」を設定
- タブ切替で「やること（自分宛）」「お願い中（相手宛）」を行き来
- 行をタップで展開 → 完了 / 担当切替 / 優先度サイクル / 編集 / 削除
- 完了したら薄くなって下に回る。完全削除は手動

## 通知
- 自分宛で「相手から新しく来た」or「期限が近い」タスクは赤丸 + タブにバッジ
- 「お願い中」側は相手が完了したものにバッジ
- アプリを開いた時点で既読扱い

## ファイル構成
- `index.html` — UI + ロジック
- `icon.svg` — アイコン (cloudbuild で PNG に変換)
