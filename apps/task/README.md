# タスク（/task/）

小西と名取の間でやることをやり取りするボード。「相手にお願いする」「自分宛のやること」を共有。

## 使い方
- ランチャーから [✅ タスク] をタップ
- 1列の縦並びで全タスク表示。左端のピル（**小 / 共 / 自**）が誰担当か
- 右下の `+` でタスク追加。「誰がやる」「優先度」「期限（任意）」
- 行を **横にスワイプ** で担当を1段階ずらす
  - 左スワイプ → 自 → 共 → 小
  - 右スワイプ → 小 → 共 → 自
- 左のピルをタップ → 3つ並んで開く → 直接担当を指定
- 行本体をタップで展開 → 完了 / 優先度サイクル / 編集 / 削除
- 完了したら薄くなって下に回る。完全削除は手動

## 通知
- 相手が新規追加したタスクで自分にも関わるもの → 赤丸
- アプリを開いた時点で既読扱い

## ファイル構成
- `index.html` — UI + ロジック
- `icon.svg` — アイコン (cloudbuild で PNG に変換)
