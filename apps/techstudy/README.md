# techstudy（/techstudy/）

IT まわりの用語・仕組み・歴史を一問一答で身につけるミニアプリ。
モーダル / FAB / ムーアの法則 / PageRank / RSA / SaaS のサブスク / NFT…
気づいたら「あ、それ知ってる」と言えるようになる、を目指す。

## 使い方

- ランチャーから [🎓 techstudy] をタップ
- 「10問にチャレンジ」で出題（選択式 + 自由記述ミックス）
- ジャンルタップで集中セッション（そのジャンルだけ10問）
- 自由記述は AI（Gemini Flash）が意味で判定（日本語/英語/カタカナ表記揺れ吸収）
- 各問題の解答後に「解説（4-6文、定義 + 由来・人物 + へぇー！トリビア）」と「Claude Code への指示例」が出る
- 10問終わると正答率に応じてレベル自動調整（≥70% で +1、<40% で −1）

## ジャンル構成（13グループ・約650ジャンル）

- IT・テックの収益化（SaaS / サブスク / LTV / MRR …）
- ITの歴史・法則・人物（ムーアの法則 / Unix の誕生 / 中本哲史 …）
- 身近な技術の仕組み（Google検索 / JPEG / QRコード / Spotify …）
- アルゴリズム・CS基礎（公開鍵暗号 / PageRank / ハミング符号 …）
- AI・LLM 基礎 / AIエージェント・ツール連携
- ブロックチェーン・Web3
- UI 部品 / UI デザイン
- データベース / API・通信
- インフラ・クラウド / セキュリティ
- 開発フロー・Claude Code
- エンジニア心得（DRY / KISS / 車輪の再発明禁止 …）
- BANAX OS 技術スタック（社内システム本体）

## 出題ロジック（成長速度に合わせる）

- 過去30日でミスした問題を最大3問 + ユーザーのレベルに近い問題を残り
- 通常セッション: 「100%未達ジャンル」優先 + レベル近接
- 集中セッション: 指定ジャンル内で出題
- 出題プールが薄くなったらバックグラウンドで **AI（Gemini Flash）が新規問題を生成**

## メンバー進捗

- メンバーのレベルと上位5グループの達成度が見える
- ランキングや競争要素は無し
- 非公開化可能（`visible_to_peers=false`）

## ファイル構成

- `index.html` — UI + ロジック（ホーム / セッション / サマリの3ビュー）
- サーバー側: `apps/keihi/server/index.js` に `/api/kotonoha/*` エンドポイント（内部名は kotonoha のまま）
- DB: `kotonoha_questions` / `kotonoha_progress` / `kotonoha_users` / ジャンル列追加
- ジャンルマスタ: `apps/keihi/server/kotonoha-genres.json`
- シード: `apps/keihi/infra/kotonoha-seed.json`（初期35問）
