# threegis 360°（/threegis/）

指でドラッグ（またはスマホを傾けて）360°見回せる、星空の砂漠のパノラマ。遊びページ。

- ランチャーには載せていない**隠しURL**（`https://keihi-496002.web.app/threegis/`）
- 外部ライブラリ・画像・ログイン一切なし。canvas だけで星空＋天の川＋砂漠を描いて、その中を見回す
- 指ドラッグで見回し／放置で自動パン。https で開けば「タップ→傾きセンサー許可」で端末を傾けて見回せる

## ファイル構成
- `index.html` — 1ファイル完結（canvas パノラマ + 操作）
