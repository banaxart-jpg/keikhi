# 図面読取検証（/zumen/）

LLM (Gemini 2.5 Pro) の建築図面・間取り図の読取精度をチェックするためのミニアプリ。

## 使い方
1. ランチャーから「図面読取」をタップ
2. 「画像を選択」で図面 / 間取り図を選ぶ（画像 or PDF）
3. 下の入力欄に質問を書いて送信
   - 「この部屋は何平米？」
   - 「玄関の幅は？」
   - 「部屋数は？」
   - 「キッチンとリビングの距離は？」
4. 同じ画像で何度でも続けて質問できる（前の Q&A も AI が文脈として持つ）
5. 違う画像を選び直すと**コンテキストはリセット**されて新しい会話

## 仕様
- 一問一答（AI には 50〜150 字以内で答えるよう指示、余計な前置き・締めなし）
- 数値や寸法には単位を必ず付ける
- 図面に明記されていない数値は「読み取れない」と素直に返す
- 推測時は「推測ですが」と前置きさせる

## 仕組み
- フロント: 画像を base64 で保持。質問送信時に画像 + 過去 Q&A 履歴を `/api/zumen/ask` に POST
- サーバー: `apps/keihi/server/index.js` の `POST /api/zumen/ask`
  - `gemini-2.5-pro` (画像理解最強) を呼ぶ
  - プロンプトに「一問一答」「単位必須」「推測は前置き」「マークダウン禁止」を強制
  - 履歴をテキストで Q/A 形式に展開して文脈として渡す（毎ターン画像も再送）

## ファイル構成
- `index.html` — UI + ロジック
- API: `apps/keihi/server/index.js` の `/api/zumen/ask`
